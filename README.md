# 📊 Day 9 – Excel Dashboard: Superstore Sales Analysis  

### 📘 Overview  
Built an interactive **Sales Analysis Dashboard** using the cleaned Superstore dataset from Day 8.  
The goal was to visualize key insights, identify regional performance, and practice building professional Excel dashboards.

---

### 🧩 Key Features
- **Pivot Tables:** Created for Category, Region, Segment, and Sales Trends.  
- **KPIs:** Total Sales, Orders, and Items Sold.  
- **Visuals Used:** Bar, Pie, and Line Charts.  
- **Interactivity:** Added slicer for Year of Order.  
- **Calculated Metrics:** Derived Sales, Quantity, and Demand-based rankings.  

---

### 🛠️ Tools & Techniques
- Microsoft Excel (Pivot Tables, Charts, Slicers)  
- Conditional Formatting & Aggregation  
- Dashboard Design & Layout Formatting
